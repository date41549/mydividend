# 要件定義：マイ配当

## プロダクト方針

**「高配当ガチ勢向けの、モダンで深掘りできる配当トラッカー」**（ポジショニング B×A ハイブリッド）

- ターゲット：配当（インカム）を積み立てる個人投資家（＝伊達さん自身がど真ん中）
- **対象資産：配当が出る資産を横断**（日本株・日本ETF・J-REIT・米国株・米国ETF）。円/ドルを併せて円換算で見れる。投信・暗号資産など配当がない資産は対象外。
- 無料：既存より綺麗・軽いモダンな基本トラッカー（万人向けの土台）
- 課金（月額）：ガチ勢が欲しい深掘り分析（差別化の核）
- データ源：MVPは手入力（規約・法律・コストを全回避）。米国資産の円換算は為替手入力。将来 J-Quants／為替API 連携を検討。
- マネタイズ：フリーミアム（広告 ＋ 月額課金）。詳細は `04_monetization.md`。
- **UI/UX方針**：モダンで可読性の高いデザイン（明るいグリーン基調・大きく等幅の数字・押せる場所が明快、ライト/ダーク対応）。詳細は `08_ui_ux_design.md`。ガチ勢向けの差別化は"見た目の硬派さ"ではなく**課金の分析深度**で担保し、無料版の見た目は初心者〜ガチ勢の裾野に効く土台に徹する。

## 非機能要件（NFR）

- **オフライン動作**：ネット接続なしで全機能（MVP時点）。データは端末内のみ。
- **クロスプラットフォーム**：iOS / Android 両対応（Expo）。
- **軽量・高速**：起動2秒以内、操作のもたつきなし。
- **プライバシー**：証券口座と連携しない・個人資産を外部送信しない、を明確な訴求点にする。
- **法務**：免責文・プライバシーポリシー・（課金導入時）特定商取引法表記を用意。
- **アクセシビリティ**：ダークモード対応、フォント可読性。

## MVP スコープ（v1）

**FR-1 〜 FR-9**。広告・課金・通知・自動取得は含めない。
「自分の保有を手入力 → 年間配当・簿価利回り・含み損益・月別カレンダーが見える → 目標に対する達成度が分かる → データが残る」を完成させて、まず**動くものを作り切る**ことを最優先。

※ 既存スプレッドシート（yoshiharu 版）で使っている簿価利回り・含み損益・目標vs実績・景気感応度・外部リンクを MVP に取り込み、そのままアプリへ移行できるようにする。NISA枠トラッカー（FR-11）は少し重いので v1.1 に回す。

## スコープ外（やらないこと）

- 証券口座とのAPI連携（提携・規制の壁）
- **特定銘柄の買い推奨・投資助言**（金商法：投資助言業登録が必要になるため公開版では絶対に載せない）
- 株探等のスクレイピングによるデータ配信（利用規約違反）
- **配当がない資産（投資信託・ビットコイン等）**（配当トラッカーに徹する。全資産の把握はマネーフォワードの領分）
- **米国資産の税引後の厳密計算**（米国源泉10%＝二重課税、外国税額控除、J-REIT特有の扱い）は MVP では割り切り、口座種別ベースの概算＋注記。将来「税引後の精度改善」として対応。
