# UI/UX 設計書：マイ配当

基本設計（[03_design.md](03_design.md)）の画面設計を、実装済みのビジュアル言語・デザインシステムとして具体化したもの。**今後のUI実装はこの文書を正とする。方針を変える時はコードより先にここを直す。**

## 0. デザイン方針（ポジショニングとの関係）

- ターゲットは「高配当を積み立てる個人投資家」（初心者〜ガチ勢）。
- **UIは「モダンで可読性の高い」方向で統一する。** 明るいグリーン基調・大きく等幅の数字・押せる場所が明快、が軸。Robinhood / Cash App / moomoo 系の"数字が主役で親しみやすい"質感。
- **「ポップ＝初心者専用／玄人が嫌う」という対立軸は取らない。** 見やすさは全ユーザーに効く。ガチ勢向けの差別化は *見た目の硬派さ* ではなく **課金の分析深度**（FR-13〜16）で担保する。無料版の見た目は万人が使いやすい土台に徹する。
- ライト／ダークの両対応を一級市民として扱う（端末設定に追従）。

### 検討の経緯（決定ログ）
- 初期に3方向を検討：**A=ダークでデータ密（証券アプリ系）／B=明るくポップ（Cash App系）／C=和モダン（セリフ・上質）**。
- **採用＝B（明るくポップ＋データ密な中身）。** 理由：日本の既存配当アプリが地味・古い中で"明るく今風"が空きレーン、ストアのスクショ映え、初心者〜ガチ勢の裾野に合う。中身（利回り/簿価/含み損益）はデータ密に保つ＝「表面はポップ、中身は本気」。
- **却下＝ヒーロー数字のセリフ体（C由来）。** Georgia等のセリフはオールドスタイル数字で桁の高さが揃わず、残高表示がむしろ不揃いに見えるため。**金額・数字はサンセリフ＋等幅（tabular-nums）**に統一。

## 2. タイポグラフィ

- 書体：端末標準サンセリフ（iOS=SF Pro / Android=Roboto / Web=system）。**セリフは使わない。**
- **数字は必ず `fontVariant: ["tabular-nums"]`**（桁を揃える）。
- ヒーロー数字：`fontWeight 800`＋`letterSpacing -1〜-1.4`（詰め）。サイズ 40〜46。
- セクションラベル：小さめ・`letterSpacing`＋`textTransform: uppercase`・`faint`／`sub` 色。
- 角丸：`radius = { sm:10, md:14, lg:20 }`。余白：`spacing = { xs:4, sm:8, md:12, lg:16, xl:24, xxl:32 }`。

## 3. コンポーネント仕様

| コンポーネント | 見た目 | 備考 |
|----------------|--------|------|
| **ヒーロー**（サマリー/カレンダー） | `heroBlock` 塗りの角丸ブロック＋白の太字数字＋補助行（月平均・利回り等） | 画面の主役 |
| **サマリーチップ** | 白カードの小タイル（税引後／評価額／含み損益） | 情報表示＝押せない（影・シェブロン無し） |
| **保有カード** | 白の浮きカード（影）／名前・メタ・年間配当（緑）／`chipBg`帯に 利回り・簿価・含み損益／業種タグ／リンク | **押せる＝影＋右端「›」＋pointer＋押下で軽く沈む** |
| **口座別サマリー** | 白カード＋ヘアライン区切りの行 | NISA/課税で分岐 |
| **並び替えバー** | チップ（配当/利回り/評価額/損益/名前）。選択中は `primary` 塗り＋白文字 | 金額系は円換算で横断ソート |
| **タブバー** | 下部3タブ。アクティブは `chipBg` のピル＋`primary` 太字（800） | 現在地を明示 |
| **FAB** | `primary` の丸ボタン＋影 | 追加フォームを開く |
| **入力欄**（為替/目標） | `chipBg` 塗り＋`primary` 枠＋角丸 | 入力可能と分かる見た目 |

## 4. アフォーダンス原則（「押せる場所を明快に」）

直前のUX改善で確立した原則。**新規UIも必ずこれに従う。**

- **押せるカードは "浮かせる"**：微かな影（`0 1px 4px rgba(11,36,24,.07)`）＋右端にシェブロン `›`＋Webは `cursor: pointer`＋押下で `scale 0.99` と背景変化。
- **押せない情報タイルは平ら**：影もシェブロンも付けない（＝押せないと分かる）。
- **リンクはチップ化**：文字の羅列でなく、`chipBg`塗り・`primary`文字・角丸999pxのピルにする。
- **入力欄は塗る**：下線だけにせず、背景＋枠で"入力できる箱"に見せる。
- **選択状態はピル＋色**：タブ・並び替えの選択中は塗り＋太字で現在地を示す。

## 5. 画面別レイアウト（実装反映済み）

1. **保有**：ヒーロー（年間配当・税引前）→ サマリーチップ3 → 為替バー（米国資産保有時）→ 口座別 → **並び替え** → 保有カード一覧 → 免責。右下にFAB。
2. **カレンダー**：緑ヒーロー（年間見込み・月平均）→ 白カードの月別バー（ピーク月をハイライト／空月は「—」）→ 注記。
3. **目標**：白カードの目標×実績（達成率バー、達成時は緑）→「目標を編集」ボタン → 編集フォーム。

## 6. アプリアイコン・スプラッシュ（実装済み）

- **ブランドマーク**：緑地（`#00C24A`→`#00A33C` グラデ）に白の「¥コイン」（リング＋¥）。テーマ色と一致。
- **生成は再現可能**：`scripts/gen-icons.mjs`（sharp で1つのSVGマークから全PNGを出力）。マーク変更時はこのスクリプトを直して再実行する。
  - `assets/icon.png`（1024・iOS/汎用）／`favicon.png`（256・web）／`splash-icon.png`（白マーク透過）
  - `android-icon-{background,foreground,monochrome}.png`（アダプティブ。前景は安全域62%に縮小）
- **app.json**：表示名「マイ配当」、bundle id `com.datz.mydividend`、`userInterfaceStyle: automatic`（ダーク対応）、アダプティブ背景 `#00C24A`、`expo-splash-screen`（緑地＋白マーク、ダークは `#0B120E`）。
