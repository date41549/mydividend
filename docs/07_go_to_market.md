# 宣伝・ユーザー獲得戦略（Go-To-Market）

「アプリを認知・インストールしてもらう」ための施策。アプリ内広告（収益源）とは別物。

## 大前提

- 個人開発＋飽和市場なので、**有料広告に金を突っ込む戦い方はしない**（CPI＝1インストール獲得単価が課金LTVを上回りやすく赤字化する）。
- 主戦場は **ASO（ストア最適化）＋ オーガニック（コンテンツ・コミュニティ）**。金より手間で獲る。
- 伊達さんは **YouTube/Twitch配信・投資の実運用（dividend-buy）・技術記事** の資産がある。これを流入経路に使えるのが強み。

## 1. ASO（アプリストア最適化）＝最重要・無料

検索で見つけてもらう土台。ここが弱いと何をしても流入しない。

- **キーワード**：「高配当」「配当金」「配当管理」「配当 記録」「NISA 配当」「増配」などをタイトル・サブタイトル・説明文に自然に含める。
- **タイトル**：`マイ配当｜高配当・NISAの配当金管理`（表示名「マイ配当」＋サブでキーワード）
- **アイコン**：一目で「配当・お金の管理」と分かる。競合と差がつく色使い。
- **スクリーンショット**：1枚目で価値が伝わるように（「年間配当が一目で分かる」等のキャプション付き）。
- **レビュー対策**：アプリ内で良いタイミング（配当を登録し終えた後など）に評価を促す。低評価は放置せず返信・改善。
- ストアの**キーワードフィールド（iOS）／説明文（Android）** を定期的に見直す。

## 2. オーガニック（伊達さんの資産を活かす）＝コスパ最強

自分のチャネルは獲得コストゼロ。ここが個人開発の勝ち筋。

- **X（旧Twitter）**：日本の高配当・NISA・新NISA界隈は活発。
  - 開発過程を発信（#個人開発 #高配当株）→ 公開時に一気に告知。
  - 毎月の買い増し（dividend-buy）の実践＋アプリのスクショを絡める＝リアルな使用例が刺さる。
- **YouTube（@Datz89oooo）/ 配信**：「配当管理アプリ作ってみた」「新NISAの配当をアプリで管理する」系の動画は投資×開発の両クラスタに届く。
- **技術記事（Zenn/Qiita）**：「Expoで配当管理アプリを個人開発した話」＝技術クラスタ＋ポートフォリオ＋アプリ導線。被リンクにもなる。
- **投資ブログ/note**：高配当運用の記事末尾にアプリ導線。

## 3. コミュニティ・口コミ

- 高配当・FIRE系のコミュニティ（X、Discord、掲示板）に**宣伝ではなく価値提供として**参加。
- **ProductHunt / 個人開発まとめ** 等への掲載（英語圏はおまけ、まずは国内）。
- 友人・投資仲間にβ配布 → 初期レビューと Android クローズドテスト要件（20人）を兼ねる。

## 4. 有料広告（やるとしても最小限・後回し）

- 基本は**やらない**。やるなら公開後に少額($数千)で **Apple Search Ads** を試す程度（自ストア内検索なので意図が明確でCVが取りやすい）。
- Meta/Google のインストール広告は個人アプリだと赤字化しやすいので**非推奨**。
- 費用対効果を必ず計測（CPI vs LTV）。合わなければ即止める。

## 5. ローンチの型（段取り）

1. **開発中**：Xで進捗を小出し発信、興味を溜める（「待ってる人」を作る）
2. **βテスト**：投資仲間・フォロワーに配布 → フィードバック＋Androidテスター要件確保
3. **公開日**：X・YouTube・技術記事を同日に集中投下（点ではなく面で告知）
4. **公開後**：レビュー依頼をアプリ内導線化、毎月の買い増し発信にアプリを常に絡める
5. **改善ループ**：ストアの流入キーワード・離脱を見て ASO と機能を回す

## 6. 指標（追うもの）

| 指標 | 意味 |
|------|------|
| ストア表示回数 → インストール率(CVR) | ASO・アイコン・スクショの良し悪し |
| インストール数（流入元別） | どのチャネルが効いてるか |
| D1/D7 継続率 | プロダクトの定着（宣伝より本質） |
| レビュー数・平均★ | 信頼と検索順位に直結 |
| 課金転換率 | マネタイズ（`04_monetization.md`） |

## 現実的な期待値

- 最初の数百DLは自分のチャネル経由がほとんど。**バズ前提にしない**。
- 継続率(D7)が悪いと何を宣伝しても穴の空いたバケツ。**まずプロダクトの定着 → その後に拡散**の順序を守る。
