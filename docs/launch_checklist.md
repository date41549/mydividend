## 事前の方針決め
- **どのストアに出す？**
  - **Android(Google Play)**：登録$25買い切り・安い。ただし新規個人アカウントは**12人×14日テスト**の関門あり。
  - **iOS(App Store)**：登録$99/年。テスト関門は無く速い。**日本の20〜30代はiPhone7〜8割**＝ターゲット到達はiOSの方が大きい。
  - → 迷うなら「iOSを先に出す＋Androidのテストを裏で並行」。安さ最優先ならAndroidのみ。

## Phase 0：アカウント・環境（半日）
- [ ] Expoアカウント作成（無料）→ `npm i -g eas-cli` → `eas login`
- [ ] プロジェクト作成：アプリのフォルダで `eas init`（`app.json` に projectId が自動で入る）
- [ ] ストア開発者登録
  - [ ] Google Play Developer（$25・買い切り）※Android出すなら
  - [ ] Apple Developer Program（$99/年）※iOS出すなら
- [ ] **プライバシーポリシーを公開URL化**（[privacy_policy.md](privacy_policy.md) をGitHub Pages等で公開＋連絡先メール記入）

## Phase 1：実機で動作確認（1日）
- [ ] `eas build -p android --profile preview`（APK生成）→ 自分のAndroid実機に入れて一通り触る
  - [ ] 銘柄の追加・編集・削除（CRUD）が正しく動く
  - [ ] ダークモード・小さめ/大きめ端末で崩れない
  - [ ] スプラッシュ・アイコンが出る
- [ ] 気になる不具合があればメモ → 直す（私に投げてOK）

## Phase 2：Androidテスター集め（★早めに並行開始・合計2〜3週間）
※Android出す場合。iOSのみなら不要。
- [ ] Play Consoleでアプリ作成 → **クローズドテスト**トラックにAAB（`eas build -p android --profile production`）をアップロード
- [ ] テスター用の **Google Group** を作り、テスターに指定
- [ ] **12人（余裕みて15人）**集める：
  - [ ] Discord「Androidクローズドテスト攻略組」で相互テスト（まず数本テストして貸しを作る）
  - [ ] Xで募集（`#Androidクローズドテスト` ＋「クローズドテスト」検索で相互声がけ）
  - [ ] 身内2〜3人（iPhoneはNG・別端末は別Googleアカウント）
- [ ] **14日連続**キープ（抜けて12未満にしない）→ テスト中にひとことフィードバックを集めておく
- [ ] 14日経過後、**本番アクセスを申請**（「何をテストして何を直したか」に答える）

## Phase 3：ストア掲載情報（半日）
- [ ] [store_listing.md](store_listing.md) から貼る：アプリ名・サブタイトル・キーワード・簡単な説明・詳細説明・リリースノート
- [ ] **スクショ撮影**（ライトモードが映える。iOS 6.7"=1290×2796 / Android 縦1080px以上）→ 上にキャプション（store_listing の構成案）
- [ ] **データ申告**：Android「データセーフティ」/ iOS「プライバシー質問票」＝ **収集なし・端末内保存・外部送信なし・トラッキングなし** で回答
- [ ] 年齢レーティング申告

## Phase 4：提出・公開
- [ ] iOS：`eas submit -p ios` → TestFlight確認 → 審査提出（1〜3日）
- [ ] Android：本番アクセス承認後、製品版へ昇格 → 審査（数時間〜数日）
- [ ] 公開🎉

## 公開後（v1.2〜）
- [ ] 反応・レビューを見る
- [ ] 広告(AdMob)・課金(RevenueCat)・深掘り分析の有料化を検討（要EAS Dev Build）
- [ ] JSだけの修正は expo-updates で審査なし配信も可
