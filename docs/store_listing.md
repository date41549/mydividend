## 詳細説明（両ストア共通・4000字以内）

```
「マイ配当」は、保有している配当株の“年間いくら・いつ入る”をひと目で見える化する、シンプルで見やすい配当管理アプリです。

■ こんな方に
・高配当株・ETFで配当（インカム）を積み立てている
・新NISAで配当投資を始めた
・証券アプリの画面がごちゃごちゃで見づらいと感じる

■ できること（すべて無料）
・年間配当を「税引前／税引後」でひと目で把握
・配当が“いつ・いくら”入るかを「月別カレンダー」で確認
・ポートフォリオの「内訳」をドーナツグラフで
  （資産種別／セクター／景気感応度／銘柄 × 評価額／配当 で切替）
・簿価利回り(YOC)・含み損益まで銘柄ごとに表示
・NISA(非課税)と特定・一般口座を分けて集計
・NISA生涯投資枠(1,800万円)の消化ゲージ
・月間／年間配当・利回り・銘柄数・取得額の目標管理
・日本株・日本ETF・J-REIT・米国株・米国ETFを横断（ドル建ては円換算）
・各銘柄から株探・IRBANK・みんかぶ 等へワンタップ
・データのバックアップ（JSON書き出し／取り込み）

■ プライバシー第一
・証券口座と連携しません。入力データは端末の中だけに保存し、外部に送信しません。

■ ご注意
本アプリは配当の記録・可視化を目的としたツールであり、投資の勧誘・助言を行うものではありません。表示される数値は手入力に基づく概算です。
```
