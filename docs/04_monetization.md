# マネタイズ設計：マイ配当

## モデル：フリーミアム（広告 ＋ 月額課金）

| プラン | 価格 | 内容 |
|--------|------|------|
| **無料** | 0円 | 基本トラッカー（保有・年間配当・月別カレンダー・利回り）＋ 控えめな広告 |
| **プレミアム（月額）** | 250〜300円/月（年額割引も検討） | 広告非表示 ＋ 深掘り分析（分散/増配追跡/税引後シミュ）＋ CSV取込 ＋ バックアップ |

- 競合「配当管理」が月280円。**同水準〜やや下**に置く。年額でLTV確保。
- **無料でも既存より綺麗で使える**ことが入口。課金は「ガチ勢の深掘り」で価値を出す。

## 課金で出す価値（無料と有料の線引き）

- 無料：日々の記録・確認（トラッカーとして完結）
- 有料のみ：
  - セクター/銘柄の分散（円グラフ）
  - 増配/減配追跡・配当推移・連続増配年数
  - NISA/特定の税引後シミュ
  - CSV取込・自動取得（v2）
  - 広告非表示・バックアップ

## 実装方針

- **広告**：Google AdMob（`react-native-google-mobile-ads`）。バナー中心、インタースティシャルは控えめ（UXを壊すと離脱＝レビュー低下）。
- **課金**：**RevenueCat** を推奨。Expo対応・Apple/Google両対応で個人開発の定番。サブスク状態管理が楽。
  - 手数料：各ストア 15〜30%（RevenueCat 自体は一定額まで無料）。
- どちらも **Expo の Development Build / EAS** が必要（Expo Go では動かないネイティブモジュール）。→ 広告・課金を入れる v1.2 の段階で EAS ビルドに移行。

## 収益試算（現実的に小さく見積もる）

飽和市場・無料の強い先行者がいる前提で、**期待値は低い**。ラフな試算：

| 指標 | 弱気 | 中位 |
|------|------|------|
| 累計DL | 2,000 | 8,000 |
| MAU | 500 | 2,000 |
| 広告 eCPM | 低 | 低〜中 |
| 課金率 | 1% | 2% |
| 月間収益（広告＋課金）| 数百〜千円 | 数千〜1万円台 |

→ **「副収入」より「学習＋ポートフォリオ作品」の価値が主**、と割り切るのが健全。当たれば伸ばす。

## 公開に必要な法務・手続き（課金導入時）

- **プライバシーポリシー**（両ストア必須。広告のデータ取得も明記）
- **特定商取引法に基づく表記**（有料課金がある場合）
- **免責文**（投資勧誘・助言ではない旨。App内とストア説明文の両方）
- Apple Developer Program（年 $99）／Google Play Developer（初回 $25）
- 年齢レーティング申告・App Tracking Transparency（iOS広告）

## マイルストーン別のマネタイズ導入順

1. **v1**：収益化なし（まず完成・自分で使う）
2. **v1.2**：AdMob バナー ＋ ストア公開（無料＋広告で市場の反応を見る）
3. **v1.3**：RevenueCat で月額課金開始（深掘り分析を有料化）
4. 反応を見て、年額プラン・価格・広告バランスを調整
